# Glossário de Domínio

> Tradução de [`docs/product/glossary.md`](../../docs/product/glossary.md). O inglês é a fonte canônica. Os termos em negrito são a tradução; os nomes em inglês usados no código e na documentação original aparecem entre parênteses.

- **Trilha de certificação (Certification track):** Uma família de conteúdo de preparação, como a certificação Java profissional.
- **Versão da prova (Exam version):** Um conjunto específico de objetivos de prova e um alvo de preparação versionado.
- **Tópico (Topic):** Uma área de conhecimento delimitada dentro de uma versão de prova.
- **Questão (Question):** A identidade lógica de autoria ao longo das revisões.
- **Revisão de questão (Question revision):** Uma versão imutável e revisável de uma questão, suas alternativas, resposta, explicação e metadados.
- **Alternativa (Option):** Uma candidata a resposta selecionável que pertence a uma revisão de questão.
- **Sessão de estudo (Study session):** Uma atividade delimitada do aluno, contendo revisões de questões selecionadas e tentativas.
- **Tentativa (Attempt):** O resultado imutável de uma resposta submetida.
- **Confiança (Confidence):** A certeza autodeclarada do aluno no momento da submissão.
- **Progresso por tópico (Topic progress):** Um resumo de evidências derivado das tentativas; não é uma nota editada manualmente.
- **Publicada (Published):** Elegível para uso em novas sessões de estudo.
- **Depreciada (Deprecated):** Mantida para o histórico, mas excluída de novas sessões.
- **Simulado (Mock exam):** Uma avaliação cronometrada montada a partir de um blueprint explícito.
- **Runner:** O futuro serviço isolado responsável por compilar e executar trechos de código não confiáveis.
