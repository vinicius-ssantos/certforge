# CertForge v0.3.0, Mock Exams and Portuguese: release notes

The [readiness review](v0.3.0-readiness.md) records the gates this passed, what a person checked by hand, and what that does not amount to — including the one check still outstanding at the time this was written.

## What it is

`v0.2.0` told a learner what was worth doing next. This one lets them **rehearse the real thing**: a timed, blueprint-based mock exam that scores like the exam will, and tells them where they stood by topic.

It also does something the roadmap never asked for: the whole interface, not only the mock, now reads in Brazilian Portuguese as well as English. It is the change most learners will meet first.

## What you can do

**As a learner**

- Open a certification track and press **Start 1Z0-830 mock**. The question count, duration and passing threshold shown are read from the server's own blueprint, not fixed copy.
- Answer, skip, flag for your own review, and navigate directly to any of the fifty questions in any order. Nothing on the screen — and nothing in the response behind it — says which option is correct while the run is open.
- Revisit an answered question: it confirms the answer was saved, and still says nothing about whether it was right.
- Finish when ready. The confirmation names exactly how many questions will count as incorrect if you submit now; that is the one irreversible step, not reaching the last question.
- Read the result: your score against the full fifty, a practice-target pill, elapsed time, a breakdown by topic, and the complete answer key and explanation for every question — including the ones you never answered.
- Switch the interface to **Português (Brasil)** with the control in the header, or back to English. The choice is remembered. Question text stays in English either way — the real exam is sat in English, and a translated question would be new content needing its own review.

## The one that matters

**The mock measures you, not the question pool.** Practice hands over the answer the moment you submit, because that is what practice is for. A mock must not do that, or a run would just be a practice session with a clock attached. While a run is open, the server refuses to answer that question — through the mock or through ordinary practice — and the one property that boundary protects is checked by a real end-to-end browser test every time anything in this project changes.

That boundary was tested under a real attack this release found in itself: before this fix, a learner could point ordinary practice at the exact questions their own open mock had drawn and read the key while the clock ran. Found and fixed before anyone reported it, because this release's whole premise depends on that boundary holding.

## Deciding the blueprint, finally

The 50-question, 120-minute, 68%-to-pass shape has carried an "unverified" caveat since it was written. Oracle's own exam storefront refused every attempt to check it directly — four of them, over five weeks. The project owner decided, on 2026-11-08, that an Oracle-maintained source, the official study guide's own co-author, and fifteen-plus independent sources agreeing with no dissent were enough evidence to drop the caveat and record a match. If a future attempt reaches the storefront and finds a different number, the blueprint will be corrected and this release notes file's successor will say so.

## Known limitations

- **The keyboard-only and screen-reader walk of the mock screens, in both languages, was outstanding when this was written.** Every release this project has shipped has required a person to do this by hand, because it is the one judgement an automated accessibility check cannot make — whether the countdown is comprehensible heard rather than seen, whether the unanswered-count warning is unambiguous, whether the topic breakdown is followable without sight. See the readiness review for its status at tag time.
- **46 of 150 questions are reviewed by a named human, who is also their author.** The other 104 are reviewed and approved by the AI reviewer, final under [ADR 0025](../adr/0025-ai-reviewer-approval-is-final.md) — disclosed on the question itself, not a hidden shortcut.
- **The Portuguese interface has had one native-speaker read, by the project's own author.** No independent speaker has read it, and no screen-reader user has heard it in Portuguese.
- **A mock result describes that one run.** It is not a readiness forecast, a mastery claim, or a prediction about the real exam, here or anywhere.
- **The five-per-topic question distribution is a CertForge practice choice**, not an Oracle-published objective weighting.
- **The interview track foundation ships in this tag, unused.** Twelve topics, a draft taxonomy, conditional content rules — and no content, and nothing a learner can reach. It is in the tree because it is sound, not because it is this release's outcome.
- Everything `v0.1.0` and `v0.2.0` listed as a limitation still applies: one backend instance, no TLS in the images, no email verification or password reset, no tracing, rate limiting held in memory per instance.

## Deferred

Interview content and any learner-facing interview surface, mock exams for any exam code other than 1Z0-830, a review queue spanning topics in one sitting, code execution, and anything that predicts readiness.
