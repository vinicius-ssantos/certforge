# CertForge v0.4.0 — Code Analysis (draft release notes)

**Release candidate, not tagged, publicly published or deployed.** See [readiness](v0.4.0-readiness.md).

## What learners gain

Once a timed Java 21 mock becomes terminal, expanding a question review shows its **fixed, verified source files and recorded output**, alongside authored explanations and each option's reasoning. The same verified material was already available in ordinary practice. While a mock is active, the answer key, explanations and solution output remain hidden, including via the practice route.

The study experience also gained responsive navigation, better continuation/review flows, keyboard-friendly code and scrollable tables, and improved mobile presentation in English and Brazilian Portuguese.

The platform uses **prevalidated examples**, not arbitrary learner Java execution. A separately isolated Java runner is proposed for `v0.5.0`.

## Editorial and test evidence

All 150 existing Java SE 21 questions carry deterministic source/evidence. This does not mean 150 newly reviewed questions. The owner expressly accepted **six** representative examples (BigDecimal, switch pattern dominance, exports/opens, requires transitive, CompletableFuture and volatile), preserving their original keys and hashes ([issue #417](https://github.com/vinicius-ssantos/certforge/issues/417)).

The prior integrated baseline passed Maven, frontend, Playwright, release-image checks, security and CodeQL. The versioning candidate must pass those gates again.

## Limitations

- Fixed code evidence is not execution of arbitrary learner code or a substitute for human editorial judgment.
- No independent Portuguese translation assessment or newly recorded manual screen-reader review for the verified-code panel.
- A mock score describes one practice run; it does not predict a real certification result or imply Oracle affiliation.
- Production requires external TLS termination, backup, monitoring and a rollback plan.

## Publication status

The `v0.4.0` tag, GitHub Release and production deployment have **not** been performed.
