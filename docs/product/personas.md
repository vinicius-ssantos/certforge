# Personas

## Primary persona: Working Java developer

A software engineer who already uses Java professionally and wants structured preparation for a certification. Time is limited, so the learner values precise explanations, visible weak areas, and sessions that can be completed in short blocks.

### Goals

- Strengthen Java fundamentals and modern language features.
- Identify gaps that daily framework work may hide.
- Build confidence through repeated evidence.
- Prepare without relying on exam dumps.

### Frustrations

- Generic quizzes that repeat questions without teaching.
- Explanations that state the answer but not the rule.
- Progress bars that ignore difficulty, confidence, and recency.
- Content that silently mixes Java versions.

## Secondary persona: Content editor

A trusted technical contributor who creates, reviews, versions, publishes, and deprecates questions.

### Goals

- Work through an explicit editorial lifecycle.
- Reference authoritative material.
- Correct published content without rewriting historical attempts.
- Identify questions with poor discrimination or ambiguous wording.

## Future persona: Certification-track maintainer

A maintainer responsible for topic taxonomy, exam-version compatibility, blueprint evolution, and quality gates. This persona does not require separate functionality in `v0.1.0`; its responsibilities are represented by administrator capabilities.
