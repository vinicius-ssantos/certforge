# Product Vision

## Vision statement

CertForge is an adaptive and verifiable technical-learning platform that helps software engineers prepare for professional certifications and technical interviews through deliberate practice, authorial content, transparent progress evidence, and deterministic technical validation.

## Initial audience

The first user is a working Java developer preparing for the Oracle Java SE 21 Developer certification while strengthening real-world Java knowledge. The committed first release serves this certification journey only.

A later audience is a software engineer preparing for technical interviews, beginning with Java backend roles. Interview preparation must build on proven study capabilities rather than creating a separate disconnected quiz product.

## Problem

Technical preparation is fragmented across books, isolated question banks, informal notes, interview lists, videos, and generic quiz tools. Learners often cannot distinguish genuine mastery from memorization, lucky guesses, or repeated exposure to the same questions. Weak areas are identified late, explanations vary in quality, and progress metrics are frequently shallow.

Interview preparation introduces an additional problem: many valuable questions are not binary right-or-wrong items. A strong answer may need to mention expected concepts, trade-offs, follow-up reasoning, and seniority-appropriate depth without pretending that subjective responses have one magical score.

## Product promise

CertForge will help a learner answer four questions:

1. What should I study now?
2. Why was my answer correct, incomplete, or incorrect?
3. Which concepts repeatedly cause mistakes or weak explanations?
4. What evidence shows that I am becoming ready for my target?

For certification preparation, the target is a defined exam. For interview preparation, the target may be a role profile or a specific job description.

## Differentiators

- Authorial questions with versioned technical review.
- Attempt history that preserves confidence and timing context.
- Topic-level progress based on evidence rather than a single opaque percentage.
- Spaced and targeted review of weak concepts.
- Mock assessments built from controlled blueprints.
- Future guided-response interview questions with explicit expected concepts, reference answers, common mistakes, and follow-up prompts.
- Future job-specific interview tracks derived from explicit job requirements.
- Future deterministic compilation and execution of Java snippets.
- AI used as a support layer, never as the unquestioned source of correctness.

## Product principles

- Deliver one demonstrable learner capability per release.
- Prefer a small reliable workflow over broad incomplete functionality.
- Keep explanations traceable to authoritative sources.
- Make progress calculations interpretable.
- Keep objective correctness separate from guided qualitative evaluation.
- Design for accessibility, privacy, and security from the start.
- Let real study usage drive later roadmap decisions.

## Long-term direction

CertForge may support additional Java versions, other technical certifications, and interview preparation tracks such as Java Backend, Spring, System Design, AWS, and Kubernetes.

The catalog may represent different preparation-track kinds while retaining profile-specific metadata and rules. Expansion is not allowed to reduce the quality of the initial Java certification track, weaken content review, or introduce abstractions without demonstrated need.
