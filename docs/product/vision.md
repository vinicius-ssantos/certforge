# Product Vision

## Vision statement

CertForge is an adaptive and verifiable learning platform that helps software engineers prepare for professional certification exams through deliberate practice, authorial content, transparent progress evidence, and deterministic technical validation.

## Initial audience

The first user is a working Java developer preparing for the Oracle Java SE 21 Developer certification while strengthening real-world Java knowledge. The initial experience must also be understandable to other professional developers with basic Java familiarity.

## Problem

Certification preparation is fragmented across books, isolated question banks, informal notes, and generic quiz tools. Learners often cannot distinguish genuine mastery from memorization, lucky guesses, or repeated exposure to the same questions. Weak areas are identified late, explanations vary in quality, and progress metrics are frequently shallow.

## Product promise

CertForge will help a learner answer four questions:

1. What should I study now?
2. Why was my answer correct or incorrect?
3. Which concepts repeatedly cause mistakes?
4. What evidence shows that I am becoming ready for the exam?

## Differentiators

- Authorial questions with versioned technical review.
- Attempt history that preserves confidence and timing context.
- Topic-level mastery based on evidence rather than a single percentage.
- Spaced and targeted review of weak concepts.
- Mock exams built from controlled blueprints.
- Future deterministic compilation and execution of Java snippets.
- AI used as a support layer, never as the unquestioned source of correctness.

## Product principles

- Deliver one demonstrable learner capability per release.
- Prefer a small reliable workflow over broad incomplete functionality.
- Keep explanations traceable to authoritative sources.
- Make progress calculations interpretable.
- Design for accessibility, privacy, and security from the start.
- Let real study usage drive later roadmap decisions.

## Long-term direction

CertForge may support additional Java versions and other technical certifications. Expansion is not allowed to reduce the quality of the initial Java track or introduce abstractions without demonstrated need.
